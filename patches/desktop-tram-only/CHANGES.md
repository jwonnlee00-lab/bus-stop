# 트램 그래프 적용

Desktop 프로젝트의 단일 순환 계산을 기존 트램 본선·지선 그래프로 교체한 수정 패키지다. 주소 검색, Transitous 버스 검색, 지도 화면은 변경하지 않았다.

## 변경 내용

- 본선 201~240 순환, 중리 분기점~241~244 지선, 233~245 지선의 허용 방향을 사용한다.
- 연결 구간의 예상 이동시간과 중간 정차시간으로 경로를 선택한다. 기존 속도·배차·정차 설정을 유지한다.
- 정거장 준비 상태는 로컬 그래프로 확인한다. 그래프가 없거나 잘못되면 임의 순환 경로를 만들지 않는다.

## 적용 방법

전체 실행 프로젝트가 아닌 수정분만 포함한다. 수정 전 프로젝트 폴더에서 `git apply --ignore-space-change --check "<이 폴더의 절대경로>/server.patch"`로 확인한 뒤 `git apply --ignore-space-change "<이 폴더의 절대경로>/server.patch"`를 실행한다. 이미 수정된 프로젝트에는 재적용하지 않는다.

이 폴더의 `lib/tram-graph.js`, `data/tram_edges.json`, `tests/tram-graph.test.js`를 같은 상대경로로 복사한다. 기존 화면이나 인증정보는 포함하지 않는다.

## 검증 결과

Desktop 프로젝트에서 `node --check server.js`와 `node --test tests/tram-graph.test.js`가 통과했다. 본선·지선 연결, 방향, 1,980개 출발·도착 조합의 최소 예상시간 등을 포함한 테스트 7개를 확인했다. 버스 연계 검증은 모의 Transitous 응답을 사용했으며 실제 외부 API 성공을 검증한 것은 아니다.
