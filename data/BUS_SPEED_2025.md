# 2025년 버스 통행속도

`bus_speed_2025.csv`는 2025년 대전광역시 교통현황조사 및 분석 보고서의 버스 통행속도 표를 전사한 데이터다. 급행 4개, 도시 70개, 외곽 34개로 총 108개 노선이며, 속도 단위는 km/h다. 오전 07~09시, 낮 12~14시, 오후 17~19시와 보고서에 실린 전체 평균을 각각 저장했다. 전체 평균을 세 시간대의 단순 평균으로 다시 계산하지 않았다.

## 원본과 추출

원본은 다운로드 폴더의 `2025 대전광역시 교통현황조사 및 분석 보고서업로드용.pdf`다. 보고서 331~334쪽은 PDF 337~340쪽에 해당한다. PDF 337쪽은 그래프이고, 표는 338쪽 41개·339쪽 41개·340쪽 26개 노선으로 이어진다. 급행·도시·외곽 평균과 대전 전체 평균 4행은 노선이 아니므로 CSV에서 제외하고 `bus_speed_2025_validation.json`에 별도 보존했다.

텍스트가 없는 이미지 PDF를 렌더링한 뒤 행 단위로 전사했다. 속도 432개 중 OCR 숫자와 일치한 값은 368개였고, 나머지 64개는 원본 행을 확대해 확인했다. 숫자 판독 보류는 없다. OCR만으로 값을 덮어쓰지 않았다. 106번은 오전 20.0, 낮 19.7, 오후 18.0, 전체 19.2다.

33-2번 도착지의 마지막 글자는 동/창을 명확히 판독하기 어려워 노선명에 `[판독불확실]`을 넣었다. 네 속도 값은 확인했지만 노선 연결은 보류했다. 원본의 명칭을 최신 명칭으로 고쳐 쓰지 않았다. 렌더링, 전사본과 OCR 대조 기록은 `sources/bus_speed_2025/`에 있고, 원본 파일 해시는 검증 JSON에 있다.

## 2026년 노선과 비교

`bus_speed_2025_matching.json`에는 기존 `bus_routing/bus_routing.json`의 169개 노선 ID를 모두 기록했다. 번호와 보고서에 표기된 기종점이 일치하는 연결 후보는 54개이고 나머지 115개는 연결하지 않았다. 보고서 쪽에서도 108개 번호 중 54개가 후보를 찾았고 54개는 찾지 못했다.

| 2026년 노선 ID의 비교 결과 | 건수 |
| --- | ---: |
| 번호와 표기 기종점 일치 | 54 |
| 보고서에 없는 번호 | 61 |
| 명칭·기종점 차이로 검토 필요 | 52 |
| 보고서 이름 판독 보류 | 1 |
| 기존 정제 자료에서 공식 ID 미확인 | 1 |

급행 1·3번은 마을 1·3번과 구분한다. 표기 기종점은 공백·문장부호만 제거해 비교하고, 기종점이 반대로 나열된 경우는 같은 구간의 후보로 인정했다. 약칭·별칭을 추정하거나 다른 번호를 동일 노선으로 합치지 않았다. 예를 들어 704번은 보고서의 원내차고지~보훈병원과 2026년 명칭의 원내동~죽동종점이 달라 보류했다. 같은 장소의 명칭 변경인지 실제 구간 변경인지는 별도 확인이 필요하다.

**54개는 번호·표기 구간의 연결 후보이며 전체 경유 구간 동일성 검증이 아니다.** 보고서 표에는 2025년 전체 정류장 순서가 없어 중간 구간 변경 여부를 확인할 수 없다. 따라서 모든 결과의 `automatic_application_allowed`를 false로 두었고 기존 경로 데이터에 속도를 적용하지 않았다. 후보의 `speed_values_2025`는 검토용이다. 미연결 노선의 값은 null이며 대전 전체 평균으로 대체하지 않았다.

## 검증

```sh
python -m unittest discover -s tests -p test_bus_speed_2025.py -v
```

108개 노선의 누락·중복과 페이지별 행 수, 106번 기준 값, 변경된 기종점의 보류, 급행·마을 번호 구분, 결측치 유지와 기존 파일 해시를 검사한다. 검증 요약은 `bus_speed_2025_validation.json`에 있다. 추출 스크립트 `scripts/build_bus_speed_2025.py`는 기존 결과가 있으면 덮어쓰지 않고 종료한다. 기존 CSV·JSON, 경로 탐색 로직과 UI는 변경하지 않았다.
