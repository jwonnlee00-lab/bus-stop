# 버스 경로 탐색용 정제 데이터

기존 버스 CSV를 읽어 좌표를 사용할 수 있는 정류장과 순번이 연속된 버스 구간을 분리했다. 경로 입력은 `bus_routing.json`이다. 정류장 2,561개 중 연결 간선에 실제 등장하는 정류장은 2,543개이며, 123개 노선의 151개 연속 구간에 단방향 간선 8,756개가 있다. 원본 CSV는 변경하지 않았다.

## 사용 기준

정류장 ID를 그대로 유지한다. 이름은 NFC 정규화 후 공백과 Unicode 문장부호만 제거해 비교하며, 이름이 같아도 서로 다른 ID를 합치지 않는다. 공백·문장부호 차이 8개는 인정했다. 좌표가 없는 227개와 이름에 다른 글자가 포함된 7개는 제외했다. 관련 시설로 보이는 이름도 확인 없이 같은 정류장으로 간주하지 않는다. 전체 비교 결과와 제외 ID는 `cleaning_report.json`의 `stop_audit`에서 확인할 수 있다.

`routes[].edges`만 경로 탐색에 사용한다. 각 간선은 원본의 같은 기준일·같은 노선에서 순번 차이가 정확히 1인 두 경유 기록에 대응한다. 순번이 증가하는 방향만 만들며 역방향·종점 연결·순환 연결을 추정하지 않는다. 반대 방향이 별도 노선 ID로 제공되면 그 ID의 기록을 사용한다.

`blocked_connections`는 원본에서 연달아 관측되지만 좌표 제외, 순번 공백 또는 미확인 노선 때문에 사용할 수 없는 구간이다. 중간 정류장을 삭제한 뒤 남은 앞뒤 정류장을 연결하지 않는다. 예를 들어 A→B→C에서 B가 제외되면 A→C 간선을 생성하지 않는다. 연결을 보류한 쌍은 500개이며 사유는 한 쌍에 여러 개일 수 있다.

같은 버스에 탑승한 상태는 `operation_date`, `rte_id`, 경유 순번, `segment_id`로 구분한다. 정류장 ID만으로 전체 기록을 이어 붙이면 끊긴 구간을 통과하거나 같은 노선의 다른 방문 순번으로 건너뛸 수 있다. `segments`는 확인된 연결 간선의 최대 연속 구간이다. 경유 기록이 하나만 남은 경우에는 정거장 관측 정보로 보존하지만 이동 간선을 만들지 않는다. `route_id_verified`는 공식 명부 확인 여부이고, `routing_eligible`는 사용 가능한 간선이 실제로 남았는지를 뜻한다.

## 51개 노선 조사

자료는 [국토교통부 버스노선 API](https://www.data.go.kr/data/15142030/openapi.do)의 운행일 `20260901` 명부다. 2026-10-21 대전(`30`), 세종(`36`), 충북(`43`), 충남(`44`)을 조회하고 모든 페이지를 저장했다. 각 지역 응답 건수는 118, 148, 1,993, 4,311개다. 호출 시각·완료 여부는 `../sources/bus_cleaning/route_research_requests.json`, 인증키를 제거한 응답은 같은 폴더에 있다.

기존 대전 노선 명부에 없던 51개 중 48개가 같은 기준일의 공식 명부와 ID가 정확히 일치했다. 세종 31개, 충북 6개, 충남 11개다. 이 결과는 해당 기준일의 등록 근거이며 현재 실시간 운행이나 향후 운행을 보장하지 않는다. 확인된 48개 중 좌표와 연속 순번이 모두 남은 5개만 이동 간선을 제공한다. 나머지 43개는 좌표 누락 또는 연속 경유 구간 부재로 간선이 없다. 기존 대전 118개를 합쳐 실제 간선이 있는 노선은 123개다.

아래 ID는 네 지역 명부에서 찾지 못해 제외했다. 검색되지 않았다는 이유로 폐선으로 판정하지 않았다.

| ID | 기존 명칭 | 결과 |
| --- | --- | --- |
| 29022140 | 81 | 공식 ID 확인 불가, 보류 |
| 30300155 | 123번(안산동대전공공어린이재활병원) | 대전시의 123번 신설 발표는 있으나 해당 ID 연결은 확인 불가, 보류 |
| 48607122 | 수원-거창 | 공식 ID 및 해당 구간 운행 확인 불가, 보류 |

123번 보조 자료는 [대전시의 2025년 6월 노선 조정·신설 발표](https://www.daejeon.go.kr/drh/board/boardNormalView.do?boardId=normal_0189&menuSeq=1632&ntatcSeq=1485743605&pageIndex=75)다. 발표의 번호·이름만으로 ID를 대체하지 않았다. 노선 51개 각각의 입력 이름, 공식 응답, 사용 가능한 간선 수와 보류 사유는 `route_id_review.json`에 있다.

## 출발·도착 누락

원본 노선의 출발·도착 ID 중 정류장 명부에 없는 ID는 `8005096`, `8007550`, `8007551`, `8007642`, `8007643`, `9007519`다. 영향받는 노선은 1001, 72-1, 72-2, 75와 ID가 서로 다른 M1 두 개다. 없는 기종점은 생성하지 않았으며 경유 기록에서 확인한 연속 구간만 유지했다. `endpoints`에는 명부 존재 여부와 노선에서 실제 관측됐는지를 각각 기록했다.

## 재현 및 검증

네트워크 호출 없이 저장된 공식 응답과 기존 CSV로 결과를 다시 생성한다.

```sh
python scripts/clean_bus_routing.py
python -m unittest discover -s tests -p test_clean_bus_routing.py -v
```

원본 경유 기록 9,425개 중 좌표·이름·노선 ID 조건을 통과한 기록은 8,908개다. 이 수치는 독립적인 이동 간선 수가 아니다. 기록 제외 수는 517개이며, 원본에서 관측된 인접 쌍 9,256개는 사용 가능 8,756개와 보류 500개로 나뉜다. 관측 범위가 대전 내부에 한정되므로 외부 지역 노선 전체가 복원됐다는 의미가 아니다.

6개 테스트에서 중간 정류장 제외, 순번 공백, 미확인 노선, 중복 순번, 이름 비교와 저장된 모든 간선의 원본 대응 관계를 확인했다. 106번의 복합터미널(52번)→아이빌딩(62번)은 10개 연속 간선으로 유지됐다. 네 입력 CSV의 SHA-256을 생성 전후 대조했다. 전체 요약은 `cleaning_report.json`에 있다. 도보·환승·이동시간은 추가하지 않았다.
