# 대전 트램 추정 좌표

대전 2호선 수소트램 가상 내비게이션을 위한 201~245번 정거장 45개의 WGS84 추정 좌표다. 218번의 기존 A 좌표는 유지했고, 나머지 44개는 공식 도면에서 확인한 도로 구간을 지도에 대조한 B 대표점이다. B는 승강장 중심이나 출입구 좌표가 아니다.

## 자료와 방법

- 명칭 기준: [2025-10-24 확정 고시](https://www.daejeon.go.kr/djTram/notify/normalBoardDetail.do?boardId=djTram_0001&menuSeq=6724&ntatcSeq=1500763152)의 번호와 명칭. PDF 글자 사이 공백·가운데점만 정리했다.
- 위치 기준: [공식 상세 위치도](https://www.daejeon.go.kr/djTram/notify/normalBoardDetail.do?boardId=djTram_0001&menuSeq=6724&ntatcSeq=1464065145)의 기존 보관본. 제목은 2025.12.지만 보관 PDF 생성일은 2026-10-15다. 이번 작업에서 PDF·CAD를 다시 다운로드하거나 CAD 좌표계를 재조사하지 않았다.
- 지도 기준: 2026-10-21 OpenStreetMap의 WGS84 도로 및 공사 중 트램 선형. **© OpenStreetMap contributors / [ODbL](https://www.openstreetmap.org/copyright)**. 지도 선형은 공식 측량 성과가 아니다.
- 공식 2쪽 노선도의 기호를 개략 지도 위치로 옮겨 초기 후보를 만들고, 각 상세 위치도의 도로·교차로·시설물 배치와 지도 도로 구간을 대조했다. 초기 지도 탐색용 정렬 정보는 `sources/tram_estimation/candidates.json`에 있다. 검토 후 대표점을 지도에 기록된 공사 선형의 해당 구간에 두었다. 207·211·212·224·225·245번은 상세도 방향 관계에 따라 초기 후보를 이동했다.
- B는 `position_type=road_segment_estimate`로 기록했다. 구간 내 위치에 수십~수백 m의 차이가 남을 수 있으며 승강장 중심으로 검증하지 않았다. 주소·건물 검색 좌표를 그대로 복사하거나 미검증 CAD X/Y를 변환하지 않았다. 추가 RMSE 계산도 하지 않았다.
- `source_page`의 쪽수는 위치 PDF의 물리적 쪽수다. 각 정거장 상세도는 번호에서 198을 뺀 쪽에 있다. `map_evidence`의 상대 경로는 `data/` 기준이며, OSM way ID·버전·선분·선분 내 비율은 `reviewed_locations.json`에 보관했다.

## 결과와 검증

| 항목 | 결과 |
|---|---:|
| 정거장 / 좌표 확보 | 45 / 45 |
| A / B / C | 1 / 44 / 0 |
| 번호 누락 / 중복 / 좌표 범위 이탈 | 0 / 0 / 0 |
| 위도 범위 | 36.299864 ~ 36.390885 |
| 경도 범위 | 127.325213 ~ 127.448613 |
| 연결 그래프 | 정거장 45개와 분기점 1개, 간선 46개, 전체 연결 |

A는 기존 정부청사 시험에서 위치를 교차 검증한 상태, B는 도로 구간 추정, C는 위치를 특정하지 못한 상태다. 소수점 6자리는 저장·재현 형식이며 그만큼의 정확도를 뜻하지 않는다. 이번 추가 검증은 번호, 좌표 범위, 노선 연결만 확인했다. 모든 승강장의 정확한 중심이나 현장 위치를 검증했다는 의미가 아니다.

211번은 한밭대로1297번길 접속부 인근의 가양 방향 구간 대표점으로 보완했다. 218번은 `36.357463, 127.381497`과 기존 메타데이터를 유지했다. 244번은 지도 공사 선형의 북측 끝 인근을 사용해 다른 B 지점보다 세부 위치의 불확실성이 크다. B 44개 전체는 향후 필요할 때 정밀 위치를 재검토할 대상이다.

## 노선 연결과 지도

공식 2쪽 노선도에 따라 201→202→…→240→201의 순환 연결, 중리네거리 분기→241→242→243→244, 233→245의 지선을 기록했다. 중리네거리의 실제 분기는 212와 213 사이이므로 정거장으로 세지 않는 `J_중리` 노드를 따로 뒀다. 번호가 연속이라는 이유로 240→241 또는 244→245를 연결하지 않았다. 그래프는 양방향 연결 관계이며 실제 열차 운행계통·배차를 정의하지 않는다.

`tram_stations_review.html`은 외부 지도 타일이나 스크립트 없이 여는 검토 지도다. 점에 마우스를 올리면 명칭·등급·좌표·메모를 볼 수 있다. PNG도 제공한다. 청록색은 OSM 공사 선형, 보라 점선은 정거장 사이의 연결 개념선으로 실제 궤도의 상세 형상이 아니다.

201~210, 211~220, 221~230, 231~240, 241~245의 중간 CSV와 근거 JSON을 `sources/tram_estimation/`에 저장했다. 이전 2건의 상세 시험 기록은 `sources/tram_pilot/PILOT_METHOD.md`로 분리했다.

```sh
python -m pip install -r requirements-tram.txt
python scripts/build_tram_review.py
```

위 명령은 저장된 CSV와 지도 응답으로 검토 지도·연결 그래프·검증 JSON을 다시 생성한다. 새 정거장 좌표를 자동 수집하는 명령은 아니다. 이전 `estimate_tram_pilot.py`는 2건 시험 재현용이며 전체 CSV 생성기로 사용하지 않는다.

## 사용 범위

기존 버스 CSV는 변경하지 않았다. 트램 번호와 버스 정류장 ID는 별개이며, 같은 이름이나 최근접 좌표만으로 환승을 확정하지 않는다. 현재 좌표와 그래프는 가상 내비게이션의 노선 비교용이다. 이동시간·도보거리·TMAP 연동·앱 UI는 구현하지 않았고 GitHub push도 하지 않았다.
