# 가상 트램 내비게이션

기존 정거장 CSV와 연결 JSON을 읽어 45개 정거장을 좌표 지도에 표시한다. 출발역과 도착역을 선택하면 이동하는 정거장 수가 가장 적은 경로를 강조하고, 출발·도착을 포함한 정거장 목록을 보여 준다. 같은 비용의 경로가 여러 개면 하나를 표시한다.

## 실행 방법

저장소 루트에서 아래 명령을 실행한 뒤 `http://127.0.0.1:8766/web/tram/`을 연다. Python 실행 명령이 `py`인 환경에서는 `python`을 `py`로 바꾼다.

```powershell
python scripts/serve_tram.py
```

HTML 파일을 직접 여는 대신 HTTP 서버를 사용해야 CSV와 JSON을 읽을 수 있다. 서버는 화면 파일과 지정된 두 데이터 파일만 제공한다. 외부 지도 서비스나 패키지 설치는 필요 없다. 서버 종료는 터미널에서 `Ctrl+C`를 누른다.

## 경로 기준

`data/tram_stations_estimated.csv`의 좌표·이름과 `data/tram_edges.json`의 연결 및 방향 허용 값을 사용한다. 정거장으로 이동할 때 비용 1, 정거장이 아닌 분기점으로 이동할 때 비용 0을 부여하는 Dijkstra 알고리즘으로 경로를 찾는다. 예를 들어 `212→분기점→241`은 1정거장 이동이다. 출발역과 도착역이 같으면 이동 수는 0이다.

좌표 격자 위의 직선은 개략 연결이며 실제 선로가 아니다. 양방향 이동과 분기점 통과는 기존 JSON의 가정을 따른다. 이동시간·시간표·환승시간은 계산하지 않는다. 기존 데이터 파일은 읽기만 한다.

## 테스트

```powershell
node tests/test_tram_router.mjs
```

45×45개 출발·도착 조합을 별도의 Floyd–Warshall 계산과 비교한다. 순환선의 짧은 방향, 분기점을 지나는 경로의 정거장 수, 두 지선 사이 이동, 동일 역 선택, 연결이 없는 그래프와 CSV 따옴표 처리를 함께 검사한다.
